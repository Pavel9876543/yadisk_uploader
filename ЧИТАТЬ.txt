YadiskUploader - установка и запуск

1. Установка из архива

Положите рядом три файла:

YadiskUploader.zip
install_yadisk_uploader.bat
ЧИТАТЬ.txt

Запустите install_yadisk_uploader.bat двойным щелчком.

Откроется окно выбора папки для распаковки. Можно оставить путь по умолчанию
или указать свой.

Примеры путей:

C:/yadisk_uploader
C:/Programs/yadisk_uploader
D:/Apps/yadisk_uploader

Не выбирайте папку установки внутри папки, из которой запущен установщик.
Например, если установщик запущен из C:/Downloads/YadiskUploader, не надо
указывать C:/Downloads/YadiskUploader/install.

После нажатия OK программа будет распакована в выбранную папку.
Ярлык YadiskUploader появится на рабочем столе автоматически.

2. Установка из уже распакованной папки

Если рядом с этим файлом уже есть YadiskUploader.exe и
install_yadisk_uploader.bat, запустите install_yadisk_uploader.bat.

Скрипт скопирует всю папку программы в выбранное место и создаст ярлык
на рабочем столе.

3. Запуск программы

После установки запускайте программу через ярлык YadiskUploader на рабочем
столе.

Также программу можно запустить напрямую из папки установки:

C:/yadisk_uploader/YadiskUploader.exe

4. Важно

Не удаляйте папку _internal. В ней находятся файлы, необходимые для запуска
программы.

Python, PyInstaller и другие инструменты пользователю устанавливать не нужно.
